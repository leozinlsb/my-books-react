# My Books

Projeto de uma aplicação web desenvolvida com React, focada em recomendações e últimos lançamentos de livros. A estilização foi feita utilizando styled-components.

## Tecnologias utilizadas

- React
- Styled Components
- Create React App

## Como rodar o projeto localmente

Para rodar este projeto, você precisa ter o Node.js instalado.

1. Clone o repositório e acesse a pasta do projeto.
2. Instale as dependências:

```bash
npm install
```

3. Inicie o servidor de desenvolvimento:

```bash
npm start
```

O navegador deve abrir automaticamente em http://localhost:3000. Qualquer alteração no código será refletida na tela automaticamente.

## Comandos úteis

- `npm start`: Inicia a aplicação.
- `npm test`: Roda os testes configurados.
- `npm run build`: Gera o build otimizado para produção na pasta `build`.
